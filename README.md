# looksie

Paste an image, see an image.  Based on a utility a friend of mine from IRC had many moons ago.

Supports Node v24.22.1+!

---

## install & run

```bash
git clone https://github.com/justinnamilee/looksie.git
cd looksie
npm install
cp private/looksie.yml-example private/looksie.yml
# modify the "looksie.yml" as you desire
node looksie.js
```
